# ANN Deep Learning — Neural Network Regression

A practical Deep Learning project demonstrating how an Artificial Neural Network (ANN) learns to predict a student's final marks from study hours, attendance, and previous marks.

This project focuses on understanding the complete neural network training workflow, including data preprocessing, neural network architecture, forward propagation, loss calculation, backpropagation, gradient-based optimization, model evaluation, and prediction.

---

## 📌 Project Overview

This project implements an Artificial Neural Network for a regression problem.

The model learns the relationship between:

- Study Hours
- Attendance
- Previous Marks

and predicts:

- Final Marks

The project is designed as a practical implementation of core Deep Learning concepts.

---

## 🎯 Objective

The main objective is to understand how a neural network can learn from numerical data and make continuous-value predictions.
